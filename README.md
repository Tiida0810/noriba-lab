# のりば設計室・公開版8.26.2

地域を選び、停留所の数と大切にしたいことを選んで比較する、自治体検討・地域学習のための試作です。

アプリURL: https://tiida0810.github.io/noriba-lab/

- 14地域の公開データと中間市の仮配置、固定研究の比較例を収録しています。
- 任意の自治体データ、写真、動画、停留所番号付きフォルダーを利用者の端末で取り込めます。アップロード用サーバーはありません。
- 私物の現地写真・動画の見本は公開版に含めません。写真登録・編集・地図HTML出力は利用できます。
- 固定研究の数値と、現在の条件で計算した値を分けます。設置可否・安全・実需要や最適配置を認定しません。
- [データの出典と利用条件](SOURCE_NOTICES.html) / [机上検証のPDF](docs/desk-validation.pdf)

## GitHub Pagesで公開

このフォルダーだけをリポジトリへ登録し、Settings → Pages → SourceでGitHub Actionsを選びます。mainへのpushで付属workflowが静的ファイルを公開します。ソフトウェアの追加ビルドは不要です。別名リポジトリのproject subpathでも相対URLで読み込みます。

ブラウザー登録時はこのフォルダー内を選び、`.github/workflows/pages.yml`と`.nojekyll`も含めてください。地域ファイルは16MiB以下の本体部品に分割済みです。既存の持ち出しZIPや元PBF・分析原本・私物写真を追加しないでください。

入力した写真・作業JSONは、公開サイトから自動でGitHubへ送信されません。外部URLや背景画像の明示的取得、YouTube等を開く操作は通信先に依存します。編集を再開するには作業JSONと現地資料JSONを保存してください。

この版は静的検算・機能模擬で確認しています。実ブラウザー、タブレット、現地運用や授業効果は別の確認です。

Workflow参考: https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages

不具合やご意見は [GitHub Issues](https://github.com/Tiida0810/noriba-lab/issues) へお願いします。fflateのMITライセンスは同部品のものです。リポジトリ全体へMITライセンスを付与したものではありません。

## スマホで写真と気づきを残す

[現地のりばメモ](field/index.html) は、道路・人口データを読み込まずに使う軽量画面です。
撮影・写真選択とメモ → 仮登録 → 内容を確認して本登録 → PCへ渡すファイル保存、の順で使います。
本登録はアプリ内の記録の確定で、自治体による承認・運行や安全の認定ではありません。
写真・メモはこの端末内に保存し、自動送信・公開しません。端末を変える場合は専用JSONで引き継ぎます。
PCの「現地資料の登録」で追加ファイルを読み込み、追加内容を確認します。仮登録は取り込まず、同じ番号は既定で保持し、選択した場合だけ写真・メモを追記します。
スマホ実機のカメラ・タッチ・保存容量・OSごとの挙動は別途確認が必要です。JPEG・PNG・WebPが対象で、HEICは対応形式へ変換してください。

## PC台帳の停留所をスマホで選ぶ

PCの現地資料台帳で「スマホ用の停留所一覧を保存」を押し、そのJSONを撮影・メモ画面で開くと、登録済みの停留所を選べます。
一覧は有効な停留所の自治体・サービス・番号・名前・座標・標高・住所だけで、写真・動画・観察メモ・履歴は含みません。
PC台帳が空の場合は、「受領MPを追加」または「新しく登録」で先に停留所を登録します。001と1は別番号として保持します。
停留所を選んでも撮影日・写真・メモは別に記録し、未確認の仮登録から内容を確認して本登録へ進みます。PCへ戻す操作は従来の追加プレビューで、一覧を開くだけではPCの台帳や計算案を変更しません。
一覧も写真メモも利用者の端末内で扱い、自動送信・公開しません。端末間はJSONファイルを渡します。

## 円による交通空白候補

## 到達記号の表示切替

地図上の人口代表点の記号を「○ 条件内」「△ 条件外」「× 判定保留」「すべて表示」から選べます。初期値は○です。人口の濃淡・MP・計算結果は変更せず、到達記号とその判定枠だけを絞り込みます。○がない場所を一律に交通空白とは扱いません。表示選択は作業保存・凡例・地図の印刷へ反映します。短い画面で編集欄が縮む高さ設定も修正しています。

## 8.21.0 写真と位置確認から停留所を登録

自治体用の「現地資料の登録」から、停留所番号_説明の写真・位置確認キャプチャをまとめて選択できます。未登録番号は新規候補になり、名称・緯度経度・地図上の位置を確認して登録します。登録済み停留所の名称・座標は写真追加では上書きしません。画像の座標読み取りは補助機能です。緯度経度の貼り付け・手入力も使えます。画像処理は同じサイトに同梱した部品で端末内に実行し、選択写真を外部へ送信しません。現地資料は専用ファイルを保存してください。台帳から配置案へ追加する際は対象地域・A/B/C案・追加内容を確認します。台帳登録や仮配置は、現地確認済み・運行開始済みを意味しません。

## 8.21.1 座標候補の選びやすさ

複数の座標候補を枠付きの縦並びで表示します。候補を選ぶと選択済みの案内に変わり、他の候補を閉じます。選んだ座標は引き続き元画像・地図上で確認してから登録します。読み取り・座標の判定・停留所登録・配置計算の方法は変更していません。

## 8.22.0 現地資料を取り込み、停留所から写真・動画を開く

現地資料JSONを確認して、既存の台帳へ追加できます。登録済み地点の座標は写真の追加で移動しません。登録した停留所は閲覧用地図から選び、写真・動画・確認メモを表示できます。同じ内容を操作できるHTMLとして保存できます。端末から登録した写真・動画は保存HTMLに含み、YouTubeなど外部リンクは通信が必要です。個別に収集した写真・動画や現地資料JSONは公開アプリに同梱しません。計算上の仮配置と実際の現地停留所を同一番号だけで結びつけません。

## 8.22.1 写真付き地図HTMLの保存

写真・動画を含む大きなHTMLは、作成完了後に表示される「② できあがったHTMLを保存」リンクから保存できます。ファイルの準備と実際の保存操作を分け、処理時間が長い場合も利用者自身の操作で保存を開始できます。登録内容・出力する停留所・写真・動画・メモの内容は変更していません。

## 8.23.0 自治体の案内図と現地写真

案内図の画像と番号の対応設定を端末側で読み込み、地図上の番号から写真・動画・メモを開けます。デフォルメされた図では画像上の対応位置を使い、緯度経度から位置を推測しません。元の登録座標や写真・動画を変更せず、案内図と資料を含む閲覧用HTMLを作成し、できあがった保存リンクから保存できます。自治体の原図・対応設定・現地写真・動画は公開アプリに同梱しません。原図を含むHTMLの公開・配布には、地図の権利者が示す利用条件の確認が必要です。

## 8.23.1 宇美町の比較例を現在の資料で開く

互換性が記録された旧資料の比較例を、地域別の作業ファイル検査を通して読み込みます。元の3案・条件を引き継ぎ、現在の道路・人口・評価資料で再計算します。元の分析結果は旧資料の結果として表示し、現在の計算値とは区別します。役場と早見保育園の比較、検討理由・次の確認の記録、作業保存・再読込を利用できます。未知の資料版や不正な乗り場・座標・条件を許可する変更ではありません。読込を取り消した場合は現在の作業と戻すための控えを維持します。

## 8.24.0 登録した停留所から案内図をつくる

登録した乗り場と、読み込まれている道路・行政界・鉄道などの資料から、番号を押して情報を確認できるオリジナル案内図を端末内で作成します。既製の地図画像や対応設定ファイルを用意しなくても試せます。乗り場の点は受領座標を使い、番号の札を動かす場合は線で元の点と結びます。

1. 「現地資料の登録」で「受領MPを追加」または「新しく登録」から停留所を登録します。写真・動画・メモも必要に応じて登録します。
2. 「写真を開く地図を選ぶ」で自治体・運行サービスを選び、「案内図を自動作成」を押します。
3. 作成が終わると、案内図の確認画面が自動で開きます。番号から乗り場の名前や登録資料を確認できます。
4. HTMLの作成ボタンで準備し、①作成後に表示される②保存リンクから保存します。元の登録資料を含む閲覧用HTMLです。

登録のない写真・動画は表示されません。道路は表示に必要な範囲で間引き、出典と未収録の資料を図に示します。川の資料は自動作成機能には含みません。市の公式案内図、運行区域、安全な徒歩経路や現地位置の保証ではありません。従来の画像と対応設定を読み込む方法も利用できます。個別の試作地図・対応設定・現地写真・動画は公開アプリへ同梱しません。
