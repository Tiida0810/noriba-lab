地図で、区域の名前と人数を確かめる

色の付いた区域にカーソルを合わせると、区域名・基準日付きの国勢調査人口・選択中の配置案の結果が分かります。区域をクリックすると、地図の下で詳しく確認できます。

まず、この順に操作します

  1. 「自治体用」→「配置案の編集」を開きます。地図の上で、表示する配置案と区域を選びます。
  2. 色の付いた区域にカーソルを合わせて、名前と人数を見ます。スマートフォンなどでは区域をタップします。
  3. 区域をクリック・タップすると、詳しい情報が地図の下に残ります。人口の資料と基準日、選択中の案、ほかの案との違いを確認します。
  4. 配置を変えた後は「計算・更新」を押し、同じ区域で結果の変化を確かめます。

乗り場や施設の点を選ぶと、その地点の説明が優先されます。区域の情報を見たいときは、区域内の点がない場所を選んでください。名前から区域を選ぶこともできます。

区域がまだ表示されない場合は、「背景・地区の表示」→「確認済み地区境界を取り込む」で、国勢調査2020の小地域境界を選び、プレビューを確認して取り込みます。

A・B・Cは、配置を保存して比べる3つの案です

A・B・Cには、それぞれ案の名前があります。名前と乗り場の配置は編集できます。Aが必ず現況、Cが必ず最適案という決まりはありません。

まず地図に表示している1つの案を確認します。3案が同じ配置なら「3つの案は同じ配置です」と表示されます。乗り場を変更して計算すると、条件内の人口目安がどう変わるかを比べられます。

地区別の表も、最初は選択中の案を1区域1行で表示します。必要なときに「A・B・Cの3案を比べる（案の名前付き）」を開いてください。

2種類の人数を分けて読みます

表示何を表すか
国勢調査人口（人）2020年10月1日時点の国勢調査による、その小地域の人口です。世帯数も同じ調査時点の値です。現在の人口ではありません。
メッシュ人口の目安（人相当）区域内の人口メッシュ代表点から求めた参考量です。選択中の案と距離・坂などの条件で、「条件内」「条件外」「判定保留」「更新待ち」に分かれます。実際の乗車人数ではありません。

例：とびたけ一丁目の国勢調査人口は467人です。メッシュ人口の目安に315人相当と表示される場合も、同じ人数を二重に表示しているわけではありません。集計方法が異なるため、それぞれの表示名と資料を見て判断します。

条件内の割合を見る場合は、同じメッシュ集計の人口目安どうしを比べます。国勢調査人口で割って、利用率やカバー率と解釈しないでください。未収録・判定保留・更新待ちは、人口0人を意味しません。

色の意味も、地図の上で選べます

区域を見分ける色は、区域の違いを示します。人口の多さを見たいときは、公式人口の濃淡を選びます。選択中の表示方法と凡例を見てから、区域を比べてください。

ここで表示するのは国勢調査の小地域です。自治会・行政区と同じ境界とは限りません。設置場所を決める際は、候補地点の安全性や土地の条件も確認します。
