地区の色分けと追加機能の使い方

公開版8.26.0 ／ 2026年10月30日

地区ごとに色を変える

  1. 「自治体用」→「配置案の編集」を開きます。
  2. 地図上部の「背景・地区の表示」を押します。
  3. 「確認済み地区境界を取り込む」を開き、「国勢調査2020の小地域境界を取り込む」を押します。
  4. 出典と区域数を確認して「プレビューを確認して取り込む」を押します。
  5. 「地区の色」で「地区を見分ける」を選び、「配置案の編集」に戻ります。

同梱境界は宇美町86・中間市81の国勢調査2020小地域です。既に取り込んだ境界は、確認なしで置き換えません。他の地域は、照合済みのGeoJSONを同じ画面から取り込めます。

国勢調査の小地域と自治会・行政区は別の単位です。自治会の実際の境界GISは未収録です。公式の地区人口、メッシュ由来の条件内人口相当、実際の乗車人数も区別しています。

背景を変える

同じ画面の「背景地図」から、OSM通常カラー、OSM薄色・モノクロ、地理院地図の淡色、背景なしを選べます。背景や透明度の表示変更で計算条件は変わりません。通信が失敗したときは背景なしで続けられます。

自治体を切り替える

「自治体用」→「地域・資料の取込」で地域を選びます。地区ごとの色分けとは別の操作です。

この版で拡充した機能

  • 地区境界・透明度・名称・出典、密集地点のまとまり、小地図。
  • 名称・番号・住所による検索と絞り込み、表と地図の連動、A/B/C並列地図と同期。
  • 案の複製・固定・一括変更、移動前の確認、取り消し・やり直し、協議記録。
  • 現地写真の拡大・説明・案内番号、CSV列対応と全行検査、範囲付き受渡し。
  • 形式13の作業保存・復元、取込前の確認、未登録入力の保護、比較票。

確認の範囲

処理・イベント・通信応答の63観点、実境界2地域、主要なブラウザー操作を確認しています。実機スマホ・ソフトキーボード・読み上げ・紙印刷・容量不足の端末・関係者試用は追加確認が必要です。案内図の画像読込と位置編集はモデル確認の範囲で、取込画面は本文貼付経路を確認しています。

全106項目について対応範囲を整理した拡充であり、全項目の本番完成認定ではありません。計算中止はその回の結果反映を止め、進行中のCPU計算の即時停止を保証するものではありません。

入力した写真・動画・作業内容を、自動で公開サーバーへ送信しません。
